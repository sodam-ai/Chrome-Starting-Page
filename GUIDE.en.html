1. What Is This? (Project Overview)

Chrome is Google's web browser (the program you use to view websites). The very first screen you see when you open Chrome, or click the "+" to open a new tab, is called the "New Tab page" or "start page."

This project, Chrome Starting Page Dashboard, turns that first screen into your own personal assistant screen. From this one page you can:

  • Keep frequently visited website addresses (bookmarks) organized by category
  • Jot down quick notes
  • Manage a to-do list (today's tasks, important items)
  • View a calendar with your schedule
  • Use a Pomodoro timer (a time-management technique: 25 minutes of focus, then a break)
  • Check off daily habits (exercise, reading, etc.)

Three things worth knowing right away

  1. It runs entirely on your own computer. This isn't a company server somewhere out on the internet — it's a tiny program (called a "server," meaning "a program that answers requests") that runs only on this computer, right now. Everything you type is stored purely as files on this computer. There's no sign-up, no login.
  2. Nothing extra needs to be installed. As long as Node.js (Section 3) is present, it just runs — no extra libraries to download.
  3. You can use it commercially, or even resell a modified version, with no legal issue. It's distributed under the very permissive "MIT License." Details in Section 18.

2. Before You Start (Prerequisites)

  • ☐ Is your operating system Windows 10/11 or macOS? — Windows has a Start menu (bottom-left); Macs have an Apple logo at the top.
  • ☐ At least 100MB of free disk space? — Almost any computer already has this.
  • ☐ Is Google Chrome installed? — If not, get it at https://www.google.com/chrome/.
  • ☐ Never used a terminal before? — That's fine. Windows install is one double-click; macOS needs one typed line.
  • ☐ Connected to the internet right now? — Might be needed once during setup. Mostly offline afterward.
  • ☐ (Optional) Want the weather widget too? — A free API key, entirely optional.

3. Software You'll Need

What is Node.js?

Node.js runs the "server" that powers this dashboard. You need version 18 or newer.

Windows users → Just skip ahead!

The setup_windows.bat file in Section 5 checks whether Node.js is missing and automatically downloads it from nodejs.org for you.

macOS users → Install it once, first

Option A — Official website (recommended)

  1. Go to https://nodejs.org
  2. Download the "LTS" version → run the installer

Option B — Homebrew

brew install node

Confirm it worked: node -v → should print v18.0.0 or higher.

5. How to Install (Step by Step)

🪟 Installing on Windows

  1. Open the folder.
  2. Double-click setup_windows.bat.
  3. A black console window automatically: backs up existing data → checks/installs Node.js if needed → registers auto-start → starts the server hidden.
  4. The final message shows an address like http://localhost:1111.
  5. You can close the window — the server keeps running.

If something goes wrong: stuck on Node.js download → check your internet connection and retry.

🍎 Installing on macOS

  1. Confirm Node.js is installed (node -v)
  2. Open Terminal (Cmd+Space → terminal)
  3. cd to the project folder
  4. Run bash setup_mac.sh
  5. Success message shows the address
Note: This installation only adds one auto-start setting — it never touches other system files or Chrome's own settings. Pointing Chrome at this page is a separate step (see step 4 of Quick Start).

9. How It Works

The screen you see (your browser) says "please save this" to a tiny server quietly running on your own computer, and that server writes it to a file.

  1. Opening http://localhost:1111 makes the server send you the screen, which then requests its own data from itself.
  2. Changing something waits ~0.3–1s, then saves via an atomic write (temp file → rename) so nothing is ever half-written.
  3. If the connection drops, an "offline mode" notice appears; changes are held in localStorage and auto-saved once reconnected. Nothing is lost.
  4. Multiple tabs stay in sync via BroadcastChannel.
  5. A service worker pre-caches the static screen files, so it still loads offline (data itself still needs the local server).
  6. The server checks data integrity on boot, auto-recovers from backups, and takes a daily automatic backup.

14. Architecture (Understanding the Structure)

① The browser screen (index.html, script.js, style.css)
        ↕  (signals only inside your own computer, port 1111)
② The small server program (server.js) — runs only on this computer
        ↕
③ Files inside the data folder (JSON) — where your actual data lives
  • ①: plain HTML/CSS/JS, no framework
  • ②: the bridge between the screen's requests and ③, only ever on this computer
  • ③: copy the whole folder to move everything to a new computer

15. Security / Data Flow (Is My Info Safe?)

Short answer: yes.

  • The server only talks to your own computer (127.0.0.1, "localhost"). No other device can reach it.
  • Everything you type stays in the data folder — nothing is sent anywhere.
What it connects to the internet forWhenIs any info sent?
Loading fontsEvery page loadNo, just design fonts
Loading bookmark iconsWhen a bookmark appearsNo, just the icon image
Weather infoOnly if you added an API keyOtherwise, never happens
Checking bookmark reachabilityOccasionally, automaticallyNo personal info sent

A full code review found no ads, tracking, or secret data transmission. The one exception: Windows setup downloads the official Node.js installer from nodejs.org, exactly once, only if it's missing.

16. Troubleshooting (Follow-Along Fixes)

Symptom: "Server disconnected."
→ Wait a few seconds → Windows: restart.bat, macOS: launchctl load ~/Library/LaunchAgents/com.dashboard.startpage.plist

Symptom: "This site can't be reached."
→ Check port.conf for the real port, then revisit

Symptom: new version, but the screen looks old.
→ Hard refresh: Ctrl+Shift+R / Cmd+Shift+R

Symptom: changed the port, nothing happened.
→ Run restart.bat or use the Settings restart button

Symptom: data looks wrong or missing.
→ Settings → Data → restore from a backup, or check Trash (30 days)

Symptom: want to remove it completely.
→ Windows: uninstall.bat / macOS: bash uninstall_mac.sh (asks about your data)

17. FAQ

Q. Can I use this at a company, or sell it?
A. Yes — MIT-licensed, just keep the copyright notice. See Section 18. (Plain summary — the LICENSE file is authoritative.)

Q. Does it need internet?
A. Mostly no — only fonts/icons/weather need it.

Q. Is my info leaking anywhere?
A. No. Section 15 lists every case.

Q. Does this replace Chrome's real new-tab screen?
A. Not automatically — you register it yourself, see Quick Start step 4.

Q. Can I see it on my phone?
A. No — deliberate, for security.

Q. Do I need to understand Node.js?
A. Not on Windows. On macOS, install it once.

Q. Can I recover something I deleted?
A. Yes — Ctrl+Z, or Trash (30 days).
