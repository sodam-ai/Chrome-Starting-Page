# Chrome Starting Page — 개인용 크롬 새 탭 대시보드

![버전](https://img.shields.io/badge/version-7.4.0-blue) ![라이선스](https://img.shields.io/badge/license-MIT-green) ![Node.js](https://img.shields.io/badge/node-%3E%3D18.0.0-brightgreen) ![의존성](https://img.shields.io/badge/dependencies-0-orange)

> 컴퓨터를 켜자마자, 또는 크롬에서 새 탭을 열자마자 뜨는 **나만의 시작 화면**입니다.
> 북마크·할 일·메모·D-Day·캘린더·뽀모도로 타이머를 한 화면에 모아두고, 모든 데이터는
> **내 컴퓨터 안에서만** 저장됩니다 — 회원가입도, 클라우드 업로드도, 광고도 없습니다.

이 문서는 **AI·메신저·컴퓨터를 오늘 처음 써보는 분**도 그대로 따라 하면 설치와 사용이
끝나도록 작성했습니다. 어려운 용어가 나오면 그 자리에서 바로 풀어서 설명합니다.

## 이 프로그램은 무엇인가요?

**크롬(Chrome) 브라우저에서 새 탭을 열 때 나오는 화면을 내가 원하는 대로 완전히
바꿔주는 프로그램**입니다. 흔히 쓰는 "새 탭 확장 프로그램"과 다른 점은, 이 프로그램은
여러분의 컴퓨터 안에서 직접 실행되는 아주 작은 서버(=프로그램)이고, 크롬은 그 서버가
보여주는 화면을 그냥 띄우기만 한다는 것입니다. 그래서 데이터가 어딘가 낯선 회사의
클라우드로 나가지 않고, 여러분의 하드디스크 안(`data` 폴더)에만 저장됩니다.

한 화면 안에 다음 기능들이 들어 있습니다.

- 카테고리별 **북마크 카드** (드래그로 순서 바꾸기, 여러 페이지로 나누기)
- **할 일(Todo) 목록** — 우선순위, 마감일, 반복 일정, 하위 작업, 리스트 보기 ↔
  **칸반 보드**(드래그로 진행 상태 변경) 전환
- **캘린더**와 **D-Day 카운트다운**
- **메모장** (마크다운 미리보기 지원)
- **뽀모도로 타이머**와 **습관 체크리스트**
- **주간 리포트** — 하루 중 처음 접속했을 때 지난 한 주간의 활동 요약을 자동으로
  보여주는 팝업
- **세계 시각**, **날씨**(선택 기능), **통합 검색**(Spotlight, 한글 초성 검색 지원)
- 다크/라이트 테마, 유리 효과(글래스모피즘), 배경화면·슬라이드쇼

**개발 언어/기술을 몰라도 됩니다.** 아래 순서대로 클릭만 하면 됩니다.

## 사전 준비물

| 항목 | 필요 여부 | 설명 |
|---|---|---|
| Windows 10/11 또는 macOS | 필수 | 이 프로그램이 실행되는 운영체제입니다. (Linux는 서버 자체는 동작하지만 자동 시작 스크립트가 없습니다.) |
| Chrome 브라우저 (또는 Edge 등 크로미움 기반 브라우저) | 필수 | 새 탭 화면으로 이 프로그램을 띄우는 창구입니다. |
| Node.js (버전 18 이상) | **불필요할 수 있음** | 이미 설치돼 있으면 그대로 씁니다. 없어도 Windows 설치 스크립트가 **자동으로 다운로드**해줍니다(아래 참고). |
| 인터넷 연결 | 설치 시 1회 필수, 이후에는 선택 | Node.js를 자동 다운로드할 때 필요합니다. 설치가 끝나면 핵심 기능은 인터넷 없이도 그대로 동작합니다 — 다만 화면 글꼴을 Google Fonts에서 불러오므로, 오프라인일 때는 자동으로 시스템 기본 글꼴로 대체됩니다(기능에는 지장 없음). 날씨 위젯(선택 기능)도 인터넷이 필요합니다. |
| 회원가입 / 결제 정보 | 불필요 | 이 프로그램은 계정을 만들 필요가 전혀 없습니다. |

> **"Node.js"가 뭔가요?** 자바스크립트(JavaScript)라는 프로그래밍 언어를 컴퓨터에서
> 직접 실행할 수 있게 해주는 실행 환경입니다. 이 프로그램은 Node.js 위에서 돌아가는
> 서버 하나로 이루어져 있습니다. 몰라도 설치·사용에는 지장이 없습니다.

## 다운로드 방법

1. GitHub 저장소 페이지로 이동합니다: **https://github.com/sodam-ai/Chrome-Starting-Page**
2. 초록색 **`Code`** 버튼을 클릭합니다.
3. **`Download ZIP`**을 클릭합니다. (Git을 쓸 줄 아신다면 `git clone` 하셔도 됩니다.)
4. 다운로드된 zip 파일을 원하는 위치에 압축 해제합니다. 예: `C:\Dashboard`
   - **주의**: 경로에 한글이나 공백이 있으면 일부 환경에서 문제가 생길 수 있으니,
     가능하면 영문·숫자로만 이루어진 짧은 경로를 추천합니다.

## 빠른 시작 3단계

**Windows 사용자**

1. 압축 해제한 폴더에서 **`setup_windows.bat`** 파일을 **더블클릭**합니다.
2. 검은 창(명령 프롬프트)이 뜨고 자동으로 설치가 진행됩니다. 완료될 때까지 기다립니다(보통 몇 초~1분, Node.js를 새로 받는 경우 최대 1~2분).
3. 크롬을 열고 `chrome://settings/onStartup`으로 이동해서, "특정 페이지 또는 페이지 모음 열기"를 선택하고 설치 완료 메시지에 나온 주소(기본값 `http://localhost:1111`)를 추가합니다.

**macOS 사용자**

1. 터미널(Terminal) 앱을 엽니다.
2. 압축 해제한 폴더로 이동한 뒤 다음을 순서대로 입력합니다.
   ```bash
   chmod +x setup_mac.sh
   ./setup_mac.sh
   ```
3. 크롬 설정에서 시작 페이지를 `http://localhost:1111`로 지정합니다.

이제 크롬에서 새 탭을 열 때마다, 또는 브라우저를 켤 때마다 이 대시보드가 나타납니다.

## 설치 방법 (상세)

### Windows — `setup_windows.bat`이 실제로 하는 일

더블클릭 한 번으로 아래 5단계가 순서대로 자동 실행됩니다.

1. **기존 데이터 보호**: `data\bookmarks.json`이 이미 있으면(재설치 상황) 손대지 않고
   그대로 두며, 추가로 안전 백업(`data\backups\safety-before-setup.json`)을 하나 만듭니다.
   처음 설치라면 필요한 빈 폴더(`data`, `data\backups`, `data\icons`, `data\profiles`,
   `assets`)를 만듭니다. **재설치해도 기존 북마크·설정은 절대 삭제되지 않습니다.**
2. **Node.js 확인**: ① 이 폴더 안에 이미 내려받아둔 포터블 Node.js가 있는지, ②
   시스템에 Node.js가 설치돼 있는지 순서대로 확인합니다. 둘 다 없으면 nodejs.org
   공식 배포처에서 포터블 버전(약 30MB)을 자동으로 내려받아 이 폴더 안(`node\`)에만
   설치합니다 — 시스템 전체에 영향을 주지 않는 방식입니다.
3. **기존 서버 중지**: 이전에 실행 중이던 서버가 있으면(재설치·업데이트 상황) 안전하게
   먼저 종료합니다.
4. **자동 시작 등록**: 컴퓨터를 켤 때 이 대시보드가 자동으로 뜨도록, 두 가지 방식을
   **동시에** 등록합니다 — ① Windows 레지스트리의 로그인 시작 프로그램 항목, ②
   시작프로그램 폴더의 바로가기(`.lnk`) 파일. 두 가지를 동시에 쓰는 이유는
   [보안과 데이터 흐름](#보안과-데이터-흐름) 문단에서 설명합니다.
5. **서버 시작**: 화면에 아무 창도 띄우지 않은 채(백그라운드) 서버를 실행합니다.

설치가 끝나면 접속 주소, Node.js 종류(시스템/포터블), 데이터 보존 안내가 화면에 표시됩니다.

### macOS — `setup_mac.sh`이 실제로 하는 일

1. 시스템에 설치된 Node.js 경로를 찾습니다(없으면 안내 메시지와 함께 종료 —
   macOS는 자동 다운로드 기능이 없으므로, [nodejs.org](https://nodejs.org)에서
   먼저 설치해야 합니다).
2. `com.dashboard.startpage.plist`라는 설정 파일을 현재 폴더 경로에 맞춰 자동 생성하고,
   `~/Library/LaunchAgents/`에 복사합니다. 이것이 macOS의 "로그인 시 자동 실행" 등록
   방식(LaunchAgent)입니다.
3. `launchctl load`로 즉시 서버를 시작합니다.

### 관리자 권한이 필요한가요?

**아니요.** 두 스크립트 모두 시스템 폴더가 아닌 사용자 개인 영역(레지스트리는
`HKCU`=현재 사용자 전용, macOS는 `~/Library/LaunchAgents`=개인 폴더)만 사용하므로
관리자 권한 없이 일반 사용자 계정으로 실행됩니다.

## 실행 · 종료 · 재시작 방법

설치를 마치면 서버는 컴퓨터를 켤 때마다 자동으로 시작되므로 평소에는 아래 내용을
몰라도 됩니다. 수동으로 조작하고 싶을 때만 참고하세요.

| 하고 싶은 것 | Windows | macOS |
|---|---|---|
| 지금 바로 재시작 | `restart.bat` 더블클릭 | `launchctl kickstart -k gui/$(id -u)/com.dashboard.startpage` |
| 완전히 끄기 | 대시보드 설정(⚙️) > 서버 관리 > 종료, 또는 `uninstall.bat` | `launchctl unload ~/Library/LaunchAgents/com.dashboard.startpage.plist` |
| 창 없이 조용히 실행만 하기 | `run_server_background.bat` 더블클릭 | 기본 동작이 이미 백그라운드입니다 |
| 접속 포트(주소) 바꾸기 | `set-port.bat` 더블클릭 후 새 포트 번호 입력 | `port.conf` 파일을 텍스트 편집기로 열어 숫자만 수정 |
| 완전히 제거(삭제) | `uninstall.bat` 더블클릭 | `uninstall_mac.sh` 실행 |

포트를 바꾼 뒤에는 반드시 서버를 재시작해야 적용됩니다. 재시작 후에는 크롬 시작
페이지 주소도 새 포트로 함께 바꿔주세요.

## 사용 방법

### 처음 화면

설치 후 처음 접속하면 짧은 온보딩(첫 사용 안내) 튜토리얼이 표시됩니다. 건너뛰어도
언제든 설정(오른쪽 위 톱니바퀴 ⚙️)에서 모든 기능을 찾을 수 있습니다.

### 북마크 추가하기

- 카드 맨 아래 빈 칸에 주소(URL)를 붙여넣고 Enter — 가장 빠른 방법입니다.
- 브라우저 주소창의 자물쇠/사이트 아이콘을 카드 위로 그대로 드래그해서 놓아도 됩니다.
- 어디서든 `Ctrl+V`(붙여넣기)만 눌러도 클립보드의 주소를 인식해 어느 카테고리에
  넣을지 물어봅니다.
- 북마크를 우클릭하면 편집·아이콘 변경·다른 페이지로 이동·삭제 메뉴가 나옵니다.
- `Ctrl` 키를 누른 채 여러 북마크를 클릭하면 한꺼번에 옮기거나 지울 수 있습니다.

### 통합 검색 (Spotlight)

키보드에서 **`F`** 키를 누르면 검색창이 뜹니다. 북마크·할 일·메모·일정을 한 번에
검색하며, 한글 초성만 입력해도 찾아줍니다(예: "ㄴㅇㅂ" → "네이버"). 검색창에
`>settings`, `>theme`, `>timer` 처럼 `>`로 시작하는 명령어를 입력하면 해당 기능으로
바로 이동합니다.

### 할 일 / 캘린더 / D-Day / 메모 / 뽀모도로

각 위젯 카드 오른쪽 위의 `+` 버튼으로 새 항목을 추가합니다. 할 일에는 우선순위,
마감일, 태그, 반복 주기(매일/매주/격주/매월), 하위 작업을 설정할 수 있습니다.
뽀모도로 타이머는 25분 집중 + 5분 휴식을 자동으로 반복하며, 완료 기록은 통계로
쌓입니다.

할 일이 10개를 넘으면 카드 아래 **"칸반 보기"** 버튼이 나타납니다. 누르면 진행
상태별(할 일 / 진행 중 / 완료 등) **칸반 보드**로 전환되어, 카드를 마우스로 끌어다
다른 상태 칸에 놓기만 하면 진행 상태가 바뀝니다. 리스트 보기로 되돌아가려면 보드
위쪽의 "리스트 뷰" 버튼을 누르면 됩니다.

또한 하루 중 이 대시보드에 처음 접속하면, 지난 한 주간의 활동(완료한 할 일 개수 등)을
요약한 **주간 리포트** 팝업이 자동으로 한 번 뜹니다. 닫으면 다음 날 접속 전까지 다시
뜨지 않습니다.

### 화면 꾸미기 (설정 > 테마)

다크/라이트/자동(운영체제 설정 따라가기) 테마, 6가지 강조 색상, 유리 효과(선명함/
보통/뿌옇게) 3단계와 흐림 정도 슬라이더, 4가지 레이아웃(기본/컴팩트/와이드/매거진),
나만의 CSS 코드 삽입까지 지원합니다. 배경화면은 이미지를 직접 올리거나(설정 > 배경),
여러 장을 올려 슬라이드쇼(자동 전환 간격 1분~24시간)로 설정할 수 있습니다.

### 데이터 내보내기 / 가져오기 / 백업 복원

설정 > 데이터 탭에서:

- **내보내기(Export)**: 모든 데이터를 JSON 파일로 내려받습니다. 배경화면·아이콘
  이미지까지 포함할지 선택할 수 있습니다.
- **가져오기(Import)**: 내보낸 JSON 파일을 다시 올려 복원합니다. 적용 전에 "북마크
  42개, 할 일 15개, 메모 3개" 같은 요약을 먼저 보여줍니다.
- **자동 백업**: 설정한 시간 간격(기본 24시간, 1~168시간 범위)마다 서버가 스스로
  전체 데이터를 백업합니다. 백업 목록에서 원하는 시점을 골라 한 번에 되돌릴 수
  있습니다.
- **프로필**: 북마크·메모·할 일·D-Day·설정을 통째로 다른 이름으로 저장해두고,
  용도별(예: "회사용" / "개인용")로 전환해가며 쓸 수 있습니다.

## 작동 방법 (아키텍처)

```
[Chrome 브라우저 새 탭]
        │  http://127.0.0.1:1111
        ▼
[server.js] ── Node.js 내장 http 모듈만 사용 (npm 의존성 0개)
        │
        ├─ 정적 파일 응답: index.html, style.css, script.js
        │   (메모리 캐시 + gzip 압축 + ETag로 재요청 최소화)
        │
        ├─ REST API (JSON) 응답: /api/bookmarks, /api/todos, /api/config 등
        │   GET  = 데이터 읽기
        │   POST = 데이터 쓰기 (같은 출처 여부 검증 후 저장)
        │
        └─ data/*.json 파일을 직접 읽고 씁니다 (데이터베이스 서버 없음)
```

- **서버**: `server.js` 하나. Node.js에 기본 내장된 `http`, `fs`, `path`, `zlib`,
  `crypto`, `net`, `child_process` 모듈만 사용합니다. `npm install`이 필요한 외부
  라이브러리가 **단 하나도 없습니다.**
- **화면(클라이언트)**: `index.html` + `style.css` + `script.js`(약 24만 자) 세 파일이
  전부입니다. React·Vue 같은 프레임워크나 별도 빌드 과정 없이, 브라우저가 그대로
  읽어서 실행합니다.
- **저장소**: 데이터베이스 서버(MySQL, MongoDB 등)를 쓰지 않고, `data/` 폴더 안의
  JSON 텍스트 파일에 직접 읽고 씁니다. 파일당 하나의 기능(북마크, 할 일, 설정 등)을
  담당합니다.
- **접속 범위**: 서버는 `127.0.0.1`(=localhost, "내 컴퓨터 자신"이라는 뜻의 특별한
  주소)에만 연결을 받습니다. 같은 네트워크(같은 와이파이)에 있는 다른 컴퓨터나
  스마트폰에서도 이 주소로는 접속할 수 없습니다 — 오직 이 컴퓨터 안에서만 열립니다.
- **포트**: 기본 1111번. 이미 다른 프로그램이 1111번을 쓰고 있으면 1112, 1113…
  순서로 최대 10개까지 자동으로 빈 포트를 찾아 실행합니다.
- **오프라인 지원**: 서비스 워커(`sw.js`)가 화면 구성 파일을 미리 저장해둬서,
  인터넷이 끊겨도 대시보드 자체는 계속 열립니다(데이터 저장은 서버가 켜져 있어야
  가능합니다 — 서버는 이 컴퓨터 안에서 도는 것이므로 인터넷과는 무관합니다).
- **외부 인터넷 통신**: 이 앱이 브라우저를 통해 외부로 내보내는 요청은 두 가지뿐입니다.
  ① **글꼴(폰트)**: 화면 디자인에 쓰는 IBM Plex Sans KR·JetBrains Mono 글꼴을
  Google Fonts(`fonts.googleapis.com`, `fonts.gstatic.com`)에서 불러옵니다 —
  인터넷이 없으면 시스템 기본 글꼴로 자동 대체되어 기능에는 지장이 없습니다.
  ② **날씨 위젯**(선택 기능): 사용자가 직접 발급받은 API 키를 설정에 입력했을 때만
  OpenWeatherMap에 도시 이름을 보내 날씨 정보를 받아옵니다. 이 두 가지 외에는 광고,
  추적 스크립트, 분석 도구를 포함해 어떤 외부 서버로도 데이터를 보내지 않습니다.

## 보안과 데이터 흐름

이 프로그램은 "항상 백그라운드에서 켜져 있는 내 컴퓨터 안 서버"라는 특성 때문에
일반적인 새 탭 확장 프로그램과는 다른 보안 설계가 필요했습니다. 아래는 실제로
**코드에 구현되어 있고, 직접 재현·검증까지 마친** 보호 장치입니다(v7.4 기준).

| 위협 | 대응 |
|---|---|
| 외부 컴퓨터에서 내 대시보드 데이터를 훔쳐보거나 조작 | 서버가 `127.0.0.1`(localhost)에만 연결을 받으므로 애초에 이 컴퓨터 밖에서는 접근 자체가 불가능합니다. |
| 악성 웹사이트가 몰래 내 북마크·할 일을 덮어씀 (CSRF) | 상태를 바꾸는 모든 요청(POST)에 대해, 브라우저가 함께 보내는 `Origin`(요청을 보낸 웹사이트 주소) 정보를 검사합니다. 이 서버 자신의 주소와 다르면 즉시 거부(403)합니다. |
| 북마크에 `javascript:` 같은 위험한 주소를 저장해 클릭 시 코드 실행 | 북마크 URL은 `http`, `https`, `ftp`, `ftps`, `mailto` 다섯 가지 스킴만 허용하는 화이트리스트로 클라이언트·서버 양쪽에서 이중 검증합니다. |
| 조작된 텍스트(제목·메모·날짜 등)가 화면에 그려질 때 스크립트로 실행됨 (XSS) | 화면에 값을 그릴 때마다 `&`, `<`, `>`, `"`, `'` 다섯 문자를 전부 안전한 문자로 치환하는 `esc()` 함수를 거칩니다. 이 함수는 `lib/esc.js` 한 곳에만 존재하며 자동 테스트로 회귀를 막습니다. |
| 파일 업로드로 서버 밖 다른 폴더에 파일을 심음 (경로 조작) | 업로드·복원 경로 모두 `..`, `~` 같은 상위 폴더 이동 패턴을 차단하고, 최종 경로가 반드시 허용된 폴더 안인지 재확인하며, 이미지 확장자만 허용합니다. |
| 너무 큰 요청으로 서버를 멈추게 함 | 모든 요청 본문은 10MB로 제한되며, 초과 시 정상적인 오류 응답(413)을 돌려줍니다. |
| 여러 창에서 동시에 저장해 데이터 파일이 깨짐 | 파일별 쓰기 잠금(락)과, "임시 파일에 먼저 쓰고 이름 바꾸기" 방식의 원자적 저장으로 중간에 프로그램이 죽어도 파일이 반쪽으로 깨지지 않습니다. |
| 데이터 파일이 어떤 이유로 손상됨 | 서버 시작마다 9개 데이터 파일의 형식을 검사하고, 손상된 파일은 가장 최근의 정상 백업으로 자동 복구합니다(백업도 없으면 빈 기본값으로). |

**왜 자동 시작을 두 가지 방식으로 등록하나요?** 일부 백신 프로그램은 "로그인마다
스크립트를 조용히 실행"하는 패턴을 악성코드의 지속성 기법과 유사하다고 오탐하여
자동 시작 등록을 지워버리는 경우가 있습니다. 그래서 레지스트리 등록과 시작프로그램
바로가기, 두 가지를 동시에 등록해두고, 서버가 켜질 때마다 둘 중 하나가 사라졌는지
확인해서 조용히 다시 등록합니다(`server.js`의 `ensureAutoStart()`). 이 자가복구는
정식 설치가 남긴 표식 파일(`.autostart-installed`)이 있는 폴더에서만 동작하므로,
개발용 사본이 실수로 진짜 자동 시작을 가로채는 사고는 구조적으로 일어나지 않습니다.

**수정 완료된 낮은 위험 하나**: 예전에는 서버 내부 6곳(프로필 저장/불러오기/삭제,
백업 복원, 가져오기, 포트 변경)에서 파일 시스템 오류가 나면 오류 메시지에 내부 경로
일부가 그대로 포함될 수 있었습니다. 지금은 이 6곳 모두 사용자에게는 안전한 일반
메시지만 보여주고, 실제 오류 내용은 서버 콘솔 로그에만 남도록 고쳤습니다.

**데이터가 저장되는 곳**: 아래 [파일 · 문서 위치](#파일-문서-위치) 표를 참고하세요.
전부 여러분의 컴퓨터 하드디스크 안이며, 이 프로그램 개발자를 포함해 그 누구도
인터넷을 통해 접근할 수 없습니다.

## 개발 워크플로우 (테스트 · 코드 구조)

이 항목은 코드를 직접 수정하거나 살펴보고 싶은 분을 위한 내용입니다. 그냥 쓰기만
하실 분은 건너뛰어도 됩니다.

- **빌드 과정이 없습니다.** 트랜스파일러(Babel 등)나 번들러(Webpack 등)를 쓰지
  않으므로, 파일을 고치고 저장하면 그대로 반영됩니다. 브라우저에서 새로고침(또는
  서버 재시작)만 하면 됩니다.
- **테스트**: `npm test`로 Node.js 내장 테스트 러너(`node --test`)가 실행됩니다.
  현재 17개 테스트(`test/esc.test.js` 6개, `test/validators.test.js` 11개)가
  XSS 이스케이프 함수와 URL 검증·백업 주기 계산 로직의 핵심 시나리오(정상값·
  경계값·악의적 입력)를 고정해두고 있습니다. Jest, Mocha 같은 별도 테스트
  프레임워크는 설치할 필요가 없습니다.
- **보조 점검 도구**: `npm run check:xss`는 `script.js`에서 `esc()` 없이 화면에
  값을 그리는 위험 지점을 찾아 목록으로 보여주는 스캐너입니다. 완벽한 자동 판정이
  아니라 "사람이 확인해야 할 후보 목록"을 뽑아주는 보조 도구입니다.
- **버그를 발견하셨다면**: GitHub 저장소의 Issues 탭에 재현 방법과 함께 남겨주시면
  됩니다.

## 문제 · 오류 대처법

| 증상 | 원인과 해결 방법 |
|---|---|
| 새 탭을 열어도 대시보드가 안 뜬다 | 서버가 꺼져 있을 수 있습니다. `restart.bat`(Windows) 또는 `launchctl load ~/Library/LaunchAgents/com.dashboard.startpage.plist`(Mac)로 다시 켜보세요. 주소창에 `http://localhost:1111`을 직접 입력해서도 확인해보세요. |
| 컴퓨터를 재부팅하면 자동 시작이 안 된다 | v7.4부터 서버가 스스로 복구를 시도하지만(자세한 원리는 [보안과 데이터 흐름](#보안과-데이터-흐름) 문단 참고), 여전히 문제가 있다면 `setup_windows.bat`을 한 번 더 실행해 재등록하세요. 백신이 계속 지운다면 백신 설정에서 이 폴더를 예외로 등록하는 방법도 있습니다. |
| "포트가 이미 사용 중입니다" 오류 | 서버가 자동으로 1112, 1113…번을 시도하므로 보통 저절로 해결됩니다. 설치 완료 메시지에 뜬 실제 포트 번호를 확인하고, 크롬 시작 페이지 주소도 그 번호로 맞춰주세요. |
| 북마크·설정이 갑자기 사라졌다 | 당황하지 말고 설정 > 데이터 > 백업 목록을 열어보세요. 서버가 자동으로 주기적 백업을 만들어두므로, 최근 백업을 골라 "복원"을 누르면 대부분 복구됩니다. |
| 파일을 업로드했는데 "Bad type" 오류가 뜬다 | 배경·아이콘 이미지는 `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`(아이콘은 `.svg`, `.ico`도 가능)만 허용됩니다. 다른 형식이면 이미지 편집기로 변환한 뒤 다시 시도하세요. |
| "File too large" / 413 오류 | 요청 본문(업로드 포함)은 10MB로 제한되어 있습니다. 더 작은 파일로 시도하세요. |
| 날씨 위젯이 안 뜬다 | 선택 기능입니다. 설정 > 날씨 탭에서 본인의 OpenWeatherMap API 키를 입력해야 표시됩니다(무료 발급 가능). 키를 입력하지 않으면 위젯 자체가 숨겨지는 것이 정상 동작입니다. |
| 설치 스크립트가 "다운로드 실패"라고 뜬다 | Node.js 자동 다운로드에는 인터넷 연결이 필요합니다. 연결을 확인한 뒤 다시 실행하거나, [nodejs.org](https://nodejs.org)에서 직접 설치한 뒤 다시 실행해보세요. |
| 다른 컴퓨터·휴대폰에서 이 주소로 접속이 안 된다 | 정상입니다. 이 서버는 보안을 위해 실행 중인 바로 그 컴퓨터에서만 열리도록 설계되어 있습니다([작동 방법 (아키텍처)](#작동-방법-아키텍처) 참고). |
| 오류가 계속되면 | 프로젝트 폴더 안의 `server.error.log` 파일을 열어보면 어떤 오류가 났는지 기록이 남아 있습니다. GitHub Issues에 그 내용을 붙여넣고 남겨주시면 도움을 드릴 수 있습니다. |

## 자주 묻는 질문 (FAQ)

**Q. 제 북마크나 메모가 개발자에게 전송되나요?**
A. 아니요. 이 프로그램에는 북마크·메모·할 일 같은 실제 사용자 데이터를 외부로
보내는 코드가 전혀 없습니다. 예외는 화면 글꼴을 받아오는 Google Fonts와, 사용자가
직접 켠 경우에만 동작하는 날씨 위젯(도시 이름만 전송) 두 가지뿐이며, 자세한 내용은
[작동 방법 (아키텍처)](#작동-방법-아키텍처)의 "외부 인터넷 통신" 항목을 참고하세요.
모든 실사용 데이터는 `data/` 폴더 안에만 저장됩니다.

**Q. 다른 컴퓨터에서도 같은 북마크를 보고 싶어요.**
A. 설정 > 데이터 > 내보내기로 백업 파일을 받아, 다른 컴퓨터에 설치한 뒤 가져오기로
불러오면 됩니다. 실시간 자동 동기화 기능은 없습니다(클라우드 서버를 쓰지 않는
설계이기 때문입니다).

**Q. 크롬이 아닌 다른 브라우저(Edge, Whale 등)에서도 되나요?**
A. 네. 크로미움(Chromium) 기반 브라우저는 새 탭 주소를 같은 방식으로 지정할 수
있어 대부분 문제없이 동작합니다. Firefox나 Safari는 새 탭 지정 방식이 달라
공식적으로 테스트하지 않았습니다.

**Q. 프로그램을 지우면 제 데이터도 같이 지워지나요?**
A. `uninstall.bat`/`uninstall_mac.sh`을 실행하면 데이터를 남길지 삭제할지 직접
물어봅니다. 그냥 폴더를 통째로 삭제하는 경우에는 `data` 폴더 안의 파일도 함께
지워지므로, 지우기 전에 내보내기로 백업을 받아두는 것을 권장합니다.

**Q. 컴퓨터가 느려지지 않나요?**
A. 서버는 npm 의존성이 0개인 아주 작은 Node.js 프로그램이라 메모리 사용량이
적습니다(보통 수십 MB 수준). 화면(정적 파일)은 메모리 캐시와 gzip 압축을 사용해
빠르게 응답합니다.

**Q. 상업적으로 써도 되나요? 이 코드로 제품을 만들어 팔아도 되나요?**
A. 아래 [법률 · 저작권 · 라이선스 · 상업적 이용](#법률-저작권-라이선스-상업적-이용) 문단을 참고하세요.

**Q. 보안 취약점을 발견했어요. 어디에 알려야 하나요?**
A. GitHub 저장소의 Issues 탭에 남겨주세요. 민감한 내용이라면 공개 이슈 대신
저장소 소유자에게 직접 연락하는 방법도 있습니다.
