Chrome Starting Page — 개인용 크롬 새 탭 대시보드

컴퓨터를 켜자마자, 또는 크롬에서 새 탭을 열자마자 뜨는 나만의 시작 화면입니다. 북마크·할 일·메모·D-Day·캘린더·뽀모도로 타이머를 한 화면에 모아두고, 모든 데이터는 내 컴퓨터 안에서만 저장됩니다 — 회원가입도, 클라우드 업로드도, 광고도 없습니다.

이 문서는 AI·메신저·컴퓨터를 오늘 처음 써보는 분도 그대로 따라 하면 설치와 사용이 끝나도록 작성했습니다. 어려운 용어가 나오면 그 자리에서 바로 풀어서 설명합니다.

이 프로그램은 무엇인가요?

크롬(Chrome) 브라우저에서 새 탭을 열 때 나오는 화면을 내가 원하는 대로 완전히 바꿔주는 프로그램입니다. 흔히 쓰는 "새 탭 확장 프로그램"과 다른 점은, 이 프로그램은 여러분의 컴퓨터 안에서 직접 실행되는 아주 작은 서버(=프로그램)이고, 크롬은 그 서버가 보여주는 화면을 그냥 띄우기만 한다는 것입니다. 그래서 데이터가 어딘가 낯선 회사의 클라우드로 나가지 않고, 여러분의 하드디스크 안(data 폴더)에만 저장됩니다.

한 화면 안에 다음 기능들이 들어 있습니다.

  • 카테고리별 북마크 카드 (드래그로 순서 바꾸기, 여러 페이지로 나누기)
  • 할 일(Todo) 목록 — 우선순위, 마감일, 반복 일정, 하위 작업, 리스트 보기 ↔ 칸반 보드(드래그로 진행 상태 변경) 전환
  • 캘린더와 D-Day 카운트다운
  • 메모장 (마크다운 미리보기 지원)
  • 뽀모도로 타이머와 습관 체크리스트
  • 주간 리포트 — 하루 중 처음 접속했을 때 지난 한 주간의 활동 요약을 자동으로 보여주는 팝업
  • 세계 시각, 날씨(선택 기능), 통합 검색(Spotlight, 한글 초성 검색 지원)
  • 다크/라이트 테마, 유리 효과(글래스모피즘), 배경화면·슬라이드쇼

개발 언어/기술을 몰라도 됩니다. 아래 순서대로 클릭만 하면 됩니다.

회원가입 / 결제 정보불필요이 프로그램은 계정을 만들 필요가 전혀 없습니다.

"Node.js"가 뭔가요? 자바스크립트(JavaScript)라는 프로그래밍 언어를 컴퓨터에서 직접 실행할 수 있게 해주는 실행 환경입니다. 이 프로그램은 Node.js 위에서 돌아가는 서버 하나로 이루어져 있습니다. 몰라도 설치·사용에는 지장이 없습니다.

다운로드 방법

  1. GitHub 저장소 페이지로 이동합니다: https://github.com/sodam-ai/Chrome-Starting-Page
  2. 초록색 Code 버튼을 클릭합니다.
  3. Download ZIP을 클릭합니다. (Git을 쓸 줄 아신다면 git clone 하셔도 됩니다.)
  4. 다운로드된 zip 파일을 원하는 위치에 압축 해제합니다. 예: C:\Dashboard
    • 주의: 경로에 한글이나 공백이 있으면 일부 환경에서 문제가 생길 수 있으니, 가능하면 영문·숫자로만 이루어진 짧은 경로를 추천합니다.

빠른 시작 3단계

Windows 사용자

  1. 압축 해제한 폴더에서 setup_windows.bat 파일을 더블클릭합니다.
  2. 검은 창(명령 프롬프트)이 뜨고 자동으로 설치가 진행됩니다. 완료될 때까지 기다립니다(보통 몇 초~1분, Node.js를 새로 받는 경우 최대 1~2분).
  3. 크롬을 열고 chrome://settings/onStartup으로 이동해서, "특정 페이지 또는 페이지 모음 열기"를 선택하고 설치 완료 메시지에 나온 주소(기본값 http://localhost:1111)를 추가합니다.

macOS 사용자

  1. 터미널(Terminal) 앱을 엽니다.
  2. 압축 해제한 폴더로 이동한 뒤 다음을 순서대로 입력합니다. ``bash chmod +x setup_mac.sh ./setup_mac.sh ``
  3. 크롬 설정에서 시작 페이지를 http://localhost:1111로 지정합니다.

이제 크롬에서 새 탭을 열 때마다, 또는 브라우저를 켤 때마다 이 대시보드가 나타납니다.

설치 방법 (상세)

Windows — setup_windows.bat이 실제로 하는 일

더블클릭 한 번으로 아래 5단계가 순서대로 자동 실행됩니다.

  1. 기존 데이터 보호: data\bookmarks.json이 이미 있으면(재설치 상황) 손대지 않고 그대로 두며, 추가로 안전 백업(data\backups\safety-before-setup.json)을 하나 만듭니다. 처음 설치라면 필요한 빈 폴더(data, data\backups, data\icons, data\profiles, assets)를 만듭니다. 재설치해도 기존 북마크·설정은 절대 삭제되지 않습니다.
  2. Node.js 확인: ① 이 폴더 안에 이미 내려받아둔 포터블 Node.js가 있는지, ② 시스템에 Node.js가 설치돼 있는지 순서대로 확인합니다. 둘 다 없으면 nodejs.org 공식 배포처에서 포터블 버전(약 30MB)을 자동으로 내려받아 이 폴더 안(node\)에만 설치합니다 — 시스템 전체에 영향을 주지 않는 방식입니다.
  3. 기존 서버 중지: 이전에 실행 중이던 서버가 있으면(재설치·업데이트 상황) 안전하게 먼저 종료합니다.
  4. 자동 시작 등록: 컴퓨터를 켤 때 이 대시보드가 자동으로 뜨도록, 두 가지 방식을 동시에 등록합니다 — ① Windows 레지스트리의 로그인 시작 프로그램 항목, ② 시작프로그램 폴더의 바로가기(.lnk) 파일. 두 가지를 동시에 쓰는 이유는 보안과 데이터 흐름 문단에서 설명합니다.
  5. 서버 시작: 화면에 아무 창도 띄우지 않은 채(백그라운드) 서버를 실행합니다.

설치가 끝나면 접속 주소, Node.js 종류(시스템/포터블), 데이터 보존 안내가 화면에 표시됩니다.

macOS — setup_mac.sh이 실제로 하는 일

  1. 시스템에 설치된 Node.js 경로를 찾습니다(없으면 안내 메시지와 함께 종료 — macOS는 자동 다운로드 기능이 없으므로, nodejs.org에서 먼저 설치해야 합니다).
  2. com.dashboard.startpage.plist라는 설정 파일을 현재 폴더 경로에 맞춰 자동 생성하고, ~/Library/LaunchAgents/에 복사합니다. 이것이 macOS의 "로그인 시 자동 실행" 등록 방식(LaunchAgent)입니다.
  3. launchctl load로 즉시 서버를 시작합니다.

관리자 권한이 필요한가요?

아니요. 두 스크립트 모두 시스템 폴더가 아닌 사용자 개인 영역(레지스트리는 HKCU=현재 사용자 전용, macOS는 ~/Library/LaunchAgents=개인 폴더)만 사용하므로 관리자 권한 없이 일반 사용자 계정으로 실행됩니다.

사용 방법

처음 화면

설치 후 처음 접속하면 짧은 온보딩(첫 사용 안내) 튜토리얼이 표시됩니다. 건너뛰어도 언제든 설정(오른쪽 위 톱니바퀴 ⚙️)에서 모든 기능을 찾을 수 있습니다.

북마크 추가하기

  • 카드 맨 아래 빈 칸에 주소(URL)를 붙여넣고 Enter — 가장 빠른 방법입니다.
  • 브라우저 주소창의 자물쇠/사이트 아이콘을 카드 위로 그대로 드래그해서 놓아도 됩니다.
  • 어디서든 Ctrl+V(붙여넣기)만 눌러도 클립보드의 주소를 인식해 어느 카테고리에 넣을지 물어봅니다.
  • 북마크를 우클릭하면 편집·아이콘 변경·다른 페이지로 이동·삭제 메뉴가 나옵니다.
  • Ctrl 키를 누른 채 여러 북마크를 클릭하면 한꺼번에 옮기거나 지울 수 있습니다.

통합 검색 (Spotlight)

키보드에서 F 키를 누르면 검색창이 뜹니다. 북마크·할 일·메모·일정을 한 번에 검색하며, 한글 초성만 입력해도 찾아줍니다(예: "ㄴㅇㅂ" → "네이버"). 검색창에 >settings, >theme, >timer 처럼 >로 시작하는 명령어를 입력하면 해당 기능으로 바로 이동합니다.

할 일 / 캘린더 / D-Day / 메모 / 뽀모도로

각 위젯 카드 오른쪽 위의 + 버튼으로 새 항목을 추가합니다. 할 일에는 우선순위, 마감일, 태그, 반복 주기(매일/매주/격주/매월), 하위 작업을 설정할 수 있습니다. 뽀모도로 타이머는 25분 집중 + 5분 휴식을 자동으로 반복하며, 완료 기록은 통계로 쌓입니다.

할 일이 10개를 넘으면 카드 아래 "칸반 보기" 버튼이 나타납니다. 누르면 진행 상태별(할 일 / 진행 중 / 완료 등) 칸반 보드로 전환되어, 카드를 마우스로 끌어다 다른 상태 칸에 놓기만 하면 진행 상태가 바뀝니다. 리스트 보기로 되돌아가려면 보드 위쪽의 "리스트 뷰" 버튼을 누르면 됩니다.

또한 하루 중 이 대시보드에 처음 접속하면, 지난 한 주간의 활동(완료한 할 일 개수 등)을 요약한 주간 리포트 팝업이 자동으로 한 번 뜹니다. 닫으면 다음 날 접속 전까지 다시 뜨지 않습니다.

화면 꾸미기 (설정 > 테마)

다크/라이트/자동(운영체제 설정 따라가기) 테마, 6가지 강조 색상, 유리 효과(선명함/ 보통/뿌옇게) 3단계와 흐림 정도 슬라이더, 4가지 레이아웃(기본/컴팩트/와이드/매거진), 나만의 CSS 코드 삽입까지 지원합니다. 배경화면은 이미지를 직접 올리거나(설정 > 배경), 여러 장을 올려 슬라이드쇼(자동 전환 간격 1분~24시간)로 설정할 수 있습니다.

데이터 내보내기 / 가져오기 / 백업 복원

설정 > 데이터 탭에서:

  • 내보내기(Export): 모든 데이터를 JSON 파일로 내려받습니다. 배경화면·아이콘 이미지까지 포함할지 선택할 수 있습니다. 기본 포트(1111)가 아닌 다른 포트를 쓰고 있다면 그 포트 설정도 함께 담깁니다(v7.5.0부터).
  • 가져오기(Import): 내보낸 JSON 파일을 다시 올려 복원합니다. 적용 전에 "북마크 42개, 할 일 15개, 메모 3개" 같은 요약을 먼저 보여줍니다. 백업에 포트 설정이 들어 있으면 그것도 함께 복원되며, 지금 쓰는 포트와 다를 때는 "재시작하면 주소가 바뀐다"는 안내가 뜹니다. 백업 파일 크기 한도는 100MB입니다(배경 사진이 들어가면 파일이 커지기 때문입니다).
  • 자동 백업: 설정한 시간 간격(기본 24시간, 1~168시간 범위)마다 서버가 스스로 전체 데이터를 백업합니다. 백업 목록에서 원하는 시점을 골라 한 번에 되돌릴 수 있습니다.
  • 프로필: 북마크·메모·할 일·D-Day·설정을 통째로 다른 이름으로 저장해두고, 용도별(예: "회사용" / "개인용")로 전환해가며 쓸 수 있습니다.

폴더를 옮기거나, 새 폴더·다른 컴퓨터에 다시 설치할 때 (중요)

이 프로그램은 폴더 이름이나 위치가 무엇이든 상관없이 동작합니다. 프로그램 안의 모든 경로가 "내 파일이 놓인 폴더"를 스스로 찾아 쓰는 방식이라, 폴더를 D:\내대시보드로 옮기든 이름을 바꾸든 그대로 실행됩니다.

왜 새 폴더가 처음엔 비어 보이나요? 프로그램이 고장 난 게 아니라, 위 표의 두 번째 경우(코드만 복사됨)에 해당하기 때문입니다. 예전 폴더의 data 폴더는 그대로 남아 있으니 데이터가 사라진 것이 아닙니다 — 위 3단계로 가져오면 됩니다.

보안과 데이터 흐름

이 프로그램은 "항상 백그라운드에서 켜져 있는 내 컴퓨터 안 서버"라는 특성 때문에 일반적인 새 탭 확장 프로그램과는 다른 보안 설계가 필요했습니다. 아래는 실제로 코드에 구현되어 있고, 직접 재현·검증까지 마친 보호 장치입니다(v7.4 기준).

위협대응
외부 컴퓨터에서 내 대시보드 데이터를 훔쳐보거나 조작서버가 127.0.0.1(localhost)에만 연결을 받으므로 애초에 이 컴퓨터 밖에서는 접근 자체가 불가능합니다.
악성 웹사이트가 몰래 내 북마크·할 일을 덮어씀 (CSRF)상태를 바꾸는 모든 요청(POST)에 대해, 브라우저가 함께 보내는 Origin(요청을 보낸 웹사이트 주소) 정보를 검사합니다. 이 서버 자신의 주소와 다르면 즉시 거부(403)합니다.
북마크에 javascript: 같은 위험한 주소를 저장해 클릭 시 코드 실행북마크 URL은 http, https, ftp, ftps, mailto 다섯 가지 스킴만 허용하는 화이트리스트로 클라이언트·서버 양쪽에서 이중 검증합니다.
조작된 텍스트(제목·메모·날짜 등)가 화면에 그려질 때 스크립트로 실행됨 (XSS)화면에 값을 그릴 때마다 &, <, >, ", ' 다섯 문자를 전부 안전한 문자로 치환하는 esc() 함수를 거칩니다. 이 함수는 lib/esc.js 한 곳에만 존재하며 자동 테스트로 회귀를 막습니다.
파일 업로드로 서버 밖 다른 폴더에 파일을 심음 (경로 조작)업로드·복원 경로 모두 .., ~ 같은 상위 폴더 이동 패턴을 차단하고, 최종 경로가 반드시 허용된 폴더 안인지 재확인하며, 이미지 확장자만 허용합니다.
너무 큰 요청으로 서버를 멈추게 함요청 본문은 10MB로 제한되며, 초과 시 정상적인 오류 응답(413)을 돌려줍니다. 단 백업 가져오기(/api/import) 한 곳만 100MB까지 허용합니다 — 배경 사진이 포함된 전체 백업은 10MB를 쉽게 넘어서, 예전에는 이 프로그램이 만든 백업 파일을 이 프로그램이 다시 못 읽는 문제가 있었기 때문입니다(v7.5.0에서 수정).
브라우저 주소창에 파일 경로를 직접 쳐서 내 데이터를 들여다봄data 폴더 안의 .json 파일(북마크·설정·백업 등)과 점(.)으로 시작하는 내부 파일은 주소로 직접 열 수 없도록 차단(403)합니다. 화면이 실제로 필요로 하는 아이콘·배경 이미지만 열립니다. v7.5.0 이전에는 http://localhost:1111/data/config.json 같은 주소로 설정 파일 전체(날씨 API 키 포함)를 열어볼 수 있었습니다.
설정과 북마크가 서로 어긋나 화면이 텅 빈 것처럼 보임어느 페이지에도 배치되지 않은 카테고리를 찾아 첫 페이지로 자동 복구하고, "카테고리 N개를 복구했습니다"라고 알려줍니다(v7.5.0). 데이터는 멀쩡한데 화면에만 안 보여서 "다 날아갔다"고 오해하는 상황을 막기 위한 장치입니다.
여러 창에서 동시에 저장해 데이터 파일이 깨짐파일별 쓰기 잠금(락)과, "임시 파일에 먼저 쓰고 이름 바꾸기" 방식의 원자적 저장으로 중간에 프로그램이 죽어도 파일이 반쪽으로 깨지지 않습니다.
데이터 파일이 어떤 이유로 손상됨서버 시작마다 9개 데이터 파일의 형식을 검사하고, 손상된 파일은 가장 최근의 정상 백업으로 자동 복구합니다(백업도 없으면 빈 기본값으로).

왜 자동 시작을 두 가지 방식으로 등록하나요? 일부 백신 프로그램은 "로그인마다 스크립트를 조용히 실행"하는 패턴을 악성코드의 지속성 기법과 유사하다고 오탐하여 자동 시작 등록을 지워버리는 경우가 있습니다. 그래서 레지스트리 등록과 시작프로그램 바로가기, 두 가지를 동시에 등록해두고, 서버가 켜질 때마다 둘 중 하나가 사라졌는지 확인해서 조용히 다시 등록합니다(server.js의 ensureAutoStart()). 이 자가복구는 정식 설치가 남긴 표식 파일(.autostart-installed)이 있는 폴더에서만 동작하므로, 개발용 사본이 실수로 진짜 자동 시작을 가로채는 사고는 구조적으로 일어나지 않습니다.

수정 완료된 낮은 위험 하나: 예전에는 서버 내부 6곳(프로필 저장/불러오기/삭제, 백업 복원, 가져오기, 포트 변경)에서 파일 시스템 오류가 나면 오류 메시지에 내부 경로 일부가 그대로 포함될 수 있었습니다. 지금은 이 6곳 모두 사용자에게는 안전한 일반 메시지만 보여주고, 실제 오류 내용은 서버 콘솔 로그에만 남도록 고쳤습니다.
