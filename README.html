📖 이것은 무엇인가요?

웹 브라우저(구글 크롬처럼 웹사이트를 방문할 수 있게 해주는 프로그램)를 열 때마다 시작 페이지(브라우저가 열리면 가장 먼저 보이는 화면)가 나타납니다. 보통은 구글 검색 화면이거나, 브라우저가 알아서 정해 준 페이지가 표시되죠.

이 프로젝트는 그 시작 페이지를 나만의 대시보드로 바꿔 줍니다 – 즐겨찾기(자주 방문하는 웹사이트 목록)를 정리하고, 메모를 쓰고, 할 일 목록을 관리하고, 습관을 추적하는 등 다양한 기능을 갖춘 아름다운 개인 홈페이지입니다.

대시보드는 작은 서버(컴퓨터 뒤에서 조용히 돌아가는 작은 프로그램, 마치 요청을 기다리는 충실한 비서 같은 존재)로 실행됩니다. 이 서버는 Node.js(아래 요구 사항 섹션에서 자세히 설명)라는 엔진(engine)을 사용합니다. 데이터는 철저히 비공개로 유지됩니다 – 어떤 회사나 인터넷 서버로도 데이터가 전송되지 않습니다. 코딩을 할 줄 몰라도 됩니다. 복잡한 소프트웨어를 설치할 필요도 없습니다. 설치 파일 하나만 실행하면 끝입니다.

핵심 세 가지: - 코딩 지식이 전혀 필요 없습니다 – 파일 하나를 더블클릭하면 설치 끝 (자연어로만 “바이브 코딩”하는 분들도 포함됩니다) - 데이터는 내 컴퓨터에만 저장됩니다 – 외부 서버로 절대 전송되지 않습니다 - 추가 소프트웨어 설치가 필요 없습니다 – 필요한 것은 자동으로 다운로드하고, 독립적으로 실행됩니다

⚡ 빠른 시작 (3단계 요약)

자세한 설명 없이 “일단 빨리 켜보고 싶다” 하시는 분들을 위한 요약입니다. 각 단계가 무엇을 하는지 궁금하시면 아래 설치 섹션에서 그림처럼 하나하나 설명해 드립니다.

  1. 다운로드 – 이 프로젝트 폴더를 통째로 내 컴퓨터의 원하는 위치에 저장합니다.
  2. 설치 스크립트 실행 – 폴더 안의 setup_windows.bat(Windows) 또는 setup_mac.sh(Mac)를 더블클릭합니다. “Setup Complete!”가 뜰 때까지 기다립니다.
  3. 크롬에서 열기 – 크롬 주소창에 http://localhost:1111을 입력하고 Enter를 누릅니다.

끝입니다. 이후로는 컴퓨터를 켤 때마다 서버가 자동으로 함께 실행되므로, 다시 설치할 필요가 없습니다 – 크롬에서 저 주소만 열면 됩니다.

🧰 요구 사항

“요구 사항”이란 시작하기 전에 준비해야 할 것들을 말합니다.

무엇이 필요한가요 왜 필요한가요 어떻게 구하나요
컴퓨터 Windows 10/11, macOS, 또는 Linux 이미 가지고 계실 겁니다
구글 크롬 (또는 아무 브라우저) 대시보드를 보기 위해 크롬 다운로드
인터넷 연결 최초 설치 시에만 필요 설치 후에는 오프라인으로 작동합니다
Node.js 대시보드를 뒤에서 실행하는 작은 프로그램 Windows: 설치 파일이 자동으로 다운로드합니다. Mac/Linux: nodejs.org에서 설치

Node.js란 무엇인가요? 대시보드를 뒤에서 움직이는 작은 엔진(engine)이라고 생각하세요. 대시보드가 “자동차”라면, Node.js는 자동차를 움직이게 하는 “엔진”입니다. 뒤에서 조용히 돌아가며 메모리를 아주 적게 사용합니다 (약 15 MB – 브라우저 탭 하나보다 적습니다). Windows에서는 설치 파일(setup_windows.bat)이 Node.js의 포터블 사본을 자동으로 다운로드하므로 직접 설치할 필요가 없습니다. 시스템에 Node.js가 이미 설치되어 있으면 그것을 사용하고, 없으면 이 프로젝트 전용 사본을 다운로드합니다.

환경 변수(environment variable)가 필요한가요? 아니요, 이 프로젝트는 환경 변수를 전혀 사용하지 않습니다. API 키(예: 날씨 위젯)를 포함한 모든 개인 설정은 .env 같은 파일이 아니라 대시보드 화면(설정 창) 또는 data/config.json에 저장됩니다 – 그래서 서버를 실행하기 전에 별도로 환경 변수를 설정해야 하는 단계가 없습니다.

“배포(deploy)”는 어떻게 하나요? 이 프로젝트는 클라우드 서버에 올리는 웹 서비스가 아니라, 내 컴퓨터에 설치해서 내 컴퓨터에서만 쓰는 프로그램입니다. 그래서 “배포”라는 절차가 따로 없고, 바로 아래 설치 섹션의 스크립트를 실행하는 것 자체가 곧 배포입니다. npm publish, 서버 업로드, 도메인 연결 같은 절차는 필요 없습니다.

📥 설치

🪟 Windows (가장 쉬움 – 코딩 불필요)

소요 시간: 약 2~5분.

1단계: 프로젝트 다운로드

이 프로젝트 폴더를 다운로드하여 원하는 곳에 놓으세요.

예시: C:\Users\내이름\Dashboard

바탕화면, 문서 폴더, 어디든 괜찮습니다. 다만 C:\Windows나 C:\Program Files 같은 시스템 폴더는 피하세요. 참고: 이 폴더를 나중에 삭제하면 대시보드도 함께 사라지므로 안전한 곳에 보관하세요.

2단계: 설치 실행

폴더를 열고 setup_windows.bat이라는 파일을 찾으세요. 톱니바퀴 같은 아이콘의 작은 스크립트 파일입니다. 더블클릭하세요.

검은색 창(명령 프롬프트(Command Prompt) – 컴퓨터에 텍스트로 지시를 내리는 방식)이 나타나며 진행 상황이 표시됩니다: 1. Node.js(엔진(engine))가 이미 컴퓨터에 있는지 확인합니다 2. 없으면 포터블 사본을 자동으로 다운로드합니다 (~30 MB – 최초 1회만) 3. Node.js가 시스템 전체에 이미 설치되어 있으면 그것을 사용합니다 4. 대시보드 서버가 백그라운드에서 시작됩니다 (보이는 창 없음) 5. 자동 시작이 등록되어 컴퓨터를 켤 때마다 자동으로 실행됩니다

“Setup Complete!”라는 메시지가 나타날 때까지 기다리세요 – 그 후에 검은색 창을 닫아도 됩니다.

3단계: 크롬에서 열기

크롬을 열고 주소창(브라우저 창 맨 위에 있는 긴 텍스트 상자, 보통 웹사이트 주소가 표시되는 곳)에 다음 주소를 입력하세요:

http://localhost:1111

그리고 Enter 키를 누르세요.

localhost:1111은 무슨 뜻인가요? “localhost”는 “이 컴퓨터”라는 뜻입니다 – 인터넷 대신 자기 컴퓨터를 들여다보라고 크롬에게 말하는 것이죠. “1111”은 포트(port) 번호입니다 (건물의 방 번호(door number)라고 생각하세요 – 설정 섹션에서 더 자세히 설명합니다).

설치 완료! 이제부터 컴퓨터를 켤 때마다 대시보드가 자동으로 시작됩니다 – 팝업도, 추가 창도 없습니다.

setup_windows.bat은 실제로 무엇을 하나요? (클릭해서 읽기)
  1. 기존 데이터가 있는지 확인하고 안전 백업을 먼저 생성합니다 (safety-before-setup.json)
  2. node/ 폴더에 Node.js 포터블 사본을 다운로드합니다 (아직 없고 시스템 Node.js도 없는 경우)
  3. 이전에 실행 중이던 대시보드 서버를 중지합니다
  4. 로그인 시 대시보드가 자동으로 시작되도록 두 가지 방법으로 동시에 등록합니다(관리자 권한 불필요) – Windows 레지스트리 등록 + 시작프로그램 폴더 바로가기. 일부 백신 프로그램이 “로그인마다 조용히 실행되는 항목”을 오탐해 둘 중 하나를 지우는 경우가 있어, 하나가 지워져도 다른 하나가 남아있도록 이중으로 등록합니다(v7.4부터). 게다가 대시보드 서버는 켜질 때마다 이 등록이 아직 살아있는지 스스로 확인하고, 없어졌으면 조용히 다시 등록합니다(자가복구) – 대시보드를 하루에도 여러 번 여시는 만큼, 한 번만 여셔도 대부분 자동으로 복구됩니다.
  5. 서버를 백그라운드에서 조용히 시작합니다 (보이는 창 없음)

시스템 전체에 아무것도 설치하지 않습니다. 자동 시작 항목 하나 외에는 Windows 설정을 수정하지 않습니다. 모든 것이 프로젝트 폴더 안에 머무릅니다.

🍎 Mac

소요 시간: 약 3분. 몇 가지 명령을 입력해야 합니다.

1단계: Node.js 설치

nodejs.org로 이동하여 웹사이트의 큰 초록색 버튼을 클릭하세요. 안내에 따라 설치를 진행합니다.

2단계: 터미널 열기

터미널(Terminal)이라는 앱을 열어야 합니다 (클릭 대신 타이핑으로 컴퓨터에 말을 거는 텍스트 기반 창입니다):

  • 키보드에서 Cmd + Space을 누르세요 (Spotlight 검색이 열립니다)
  • Terminal을 입력하고 Enter를 누르세요
  • 텍스트 프롬프트가 있는 창이 나타납니다 – 여기에 명령을 입력합니다

3단계: 프로젝트 폴더로 이동

다음 명령을 입력하고 Enter를 누르세요. 터미널에게 프로젝트를 놓아둔 폴더로 “이동하라”고 지시하는 것입니다:

cd ~/Dashboard

~/Dashboard를 실제로 프로젝트 폴더를 놓아둔 경로로 바꾸세요. cd 명령은 “change directory”(디렉토리 변경, 즉 폴더로 이동)라는 뜻입니다. ~ 기호는 홈 폴더를 의미합니다.

4단계: 설치 파일에 실행 권한 부여

chmod +x setup_mac.sh

chmod 명령은 설치 파일에 실행 권한을 부여합니다. Mac에서는 보안상 이 단계가 필요합니다.

5단계: 설치 실행

./setup_mac.sh

./ 접두사는 “현재 폴더에 있는 이 파일을 실행하라”는 뜻입니다.

6단계: 크롬에서 열기

크롬을 열고 다음 주소로 이동하세요:

http://localhost:1111

7단계: 완료!

대시보드는 로그인할 때마다 자동으로 시작됩니다. 이제 터미널을 닫아도 됩니다.

🐧 Linux

  1. nodejs.org 또는 패키지 관리자에서 Node.js를 설치하세요 (예: sudo apt install nodejs)

  2. 터미널(명령을 입력하는 텍스트 창 – 대부분의 Linux 시스템에서 Ctrl+Alt+T로 엽니다)을 여세요

  3. 프로젝트 폴더로 이동하고 서버를 실행하세요:

    cd ~/Dashboard
node server.js

  4. 크롬을 열고 http://localhost:1111로 이동하세요

systemd로 자동 시작 설정하기 (클릭해서 읽기)

systemd는 대부분의 Linux 시스템에 내장된 도구로, 컴퓨터가 부팅될 때 프로그램을 자동으로 시작할 수 있습니다. 대시보드가 자동으로 시작되도록 systemd “서비스”를 생성하세요:

sudo tee /etc/systemd/system/dashboard.service << EOF
[Unit]
Description=Chrome Starting Page Dashboard
After=network.target

[Service]
Type=simple
User=$USER
WorkingDirectory=$HOME/Dashboard
ExecStart=$(which node) server.js
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable dashboard
sudo systemctl start dashboard

$HOME/Dashboard를 실제 프로젝트 폴더 경로로 바꾸세요 (다른 위치인 경우).

포트 번호 변경

“포트”란 무엇인가요? 건물의 방 번호(door number)라고 생각하세요. 컴퓨터에는 이런 “방”이 수천 개 있고, 각 프로그램이 서로 다른 방을 사용합니다. 대시보드는 기본적으로 방 번호 1111을 사용합니다. 다른 프로그램이 이미 그 방을 쓰고 있다면, 다른 번호를 골라야 합니다.

대시보드는 기본적으로 포트 1111에서 실행됩니다. 변경하려면:

방법 어떻게
대시보드에서 (가장 쉬움) 설정 > 데이터 > 서버 관리 > 새 포트 입력 > “변경” 클릭
파일 더블클릭 set-port.bat 실행, 번호 입력 (예: 8080), Enter
텍스트 파일 편집 프로젝트 폴더의 port.conf 파일을 만들거나 편집하고, 안에 번호만 적기
명령줄 node server.js 8080 실행

포트를 변경한 후에는 크롬 시작 페이지 주소도 업데이트하세요 (예: http://localhost:8080).

💾 데이터 안전

내 데이터는 어디에 저장되나요?

모든 데이터는 프로젝트 안의 data/ 폴더에 저장됩니다. 이 폴더는 설치, 재시작, 업데이트 스크립트에 의해 절대 삭제되지 않습니다. 외부 서버로 전송되는 것도 전혀 없습니다.

마치 책상 서랍에 일기장(diary)을 넣어 두는 것과 같습니다 – 내 컴퓨터의 내 폴더에 그대로 머물러 있고, 나만 볼 수 있습니다.

자동 백업

서버가 스마트 보존 일정에 따라 자동으로 백업을 생성합니다. 별도로 할 일은 없습니다.

시간 범위 유지되는 백업 수
최근 7일 모든 백업 유지
8일~30일 하루에 백업 1개
30일 초과 자동 삭제
최대 합계 백업 파일 50개

백업은 data/backups/에 저장됩니다.

백업 목록 및 복원

대시보드에서 직접 모든 백업을 탐색하고 복원할 수 있습니다:

  1. 설정 > 데이터로 이동하세요
  2. 날짜와 파일 크기가 포함된 모든 백업 목록이 표시됩니다
  3. 원하는 백업 옆의 “복원”을 클릭하면 해당 시점으로 대시보드를 되돌릴 수 있습니다

실수로 무언가를 삭제했거나, 설정을 변경하고 되돌리고 싶을 때 유용합니다.

가져오기 미리보기: 가져오기가 적용되기 전에, 각 항목 유형별 개수를 보여주는 요약 화면이 표시됩니다 (예: “북마크 42개, 메모 5개, 할 일 12개”). 이를 통해 현재 데이터를 덮어쓰기 전에 파일이 올바른지 확인할 수 있습니다.

내보내기 파일을 USB 드라이브나 클라우드 저장소(구글 드라이브 등)에 저장해 두면 더욱 안전합니다. 마치 여행 가방(travel bag)에 소중한 물건을 넣어 두는 것처럼요.

다른 컴퓨터로 이동

  1. 기존 컴퓨터에서: 데이터를 내보내기 (설정 > 데이터 > 내보내기)
  2. 다운로드된 파일을 새 컴퓨터로 복사 (USB, 이메일, 클라우드 드라이브 – 무엇이든 됩니다)
  3. 새 컴퓨터에서: 대시보드를 설치한 뒤 파일을 가져오기 (설정 > 데이터 > 가져오기)
  4. 완료 – 대시보드가 똑같이 보입니다

대안 방법: 기존 컴퓨터의 data/ 폴더 전체를 복사하여 새 컴퓨터의 프로젝트 폴더 안 같은 위치에 붙여넣으세요.

재설치 시 어떻게 되나요?

setup_windows.bat을 다시 실행하면:

  1. 현재 데이터의 안전 백업을 먼저 생성합니다 (백업 폴더에 safety-before-setup.json으로 저장)
  2. 기존 데이터를 모두 그대로 유지합니다 – 아무것도 삭제되지 않습니다
  3. 부팅 시 대시보드가 실행되도록 자동 시작을 재등록합니다
  4. 최신 파일로 서버를 재시작합니다

북마크, 메모, 할 일, 설정 모두 그대로 있습니다. 아무것도 사라지지 않습니다.

  2. 프로젝트 파일을 새 버전으로 교체하세요 (기존 파일을 새 파일로 덮어쓰기)

🗑️ 제거 (깨끗한 삭제)

Windows (권장)

  1. uninstall.bat을 더블클릭하세요
  2. 자동으로 다음을 수행합니다:
    • 서버 중지
    • Windows 레지스트리 및 시작프로그램 폴더에서 자동 시작 제거
    • 데이터를 유지할지 삭제할지 선택 (직접 선택)
    • 로그 파일 및 임시 파일 정리
  3. 이후 프로젝트 폴더 전체를 안전하게 삭제할 수 있습니다
  4. 크롬에서 chrome://settings/onStartup으로 이동하여 localhost 항목을 제거하세요

시스템에 흔적이 남지 않습니다. 다른 프로그램에 영향을 주지 않습니다. 이 프로그램은 시스템 파일을 수정하지 않으므로, 폴더를 삭제하면 깨끗하게 제거됩니다.

Mac

가장 쉬운 방법: 터미널을 열고 프로젝트 폴더로 이동한 뒤 제거 스크립트를 실행하세요:

cd ~/Dashboard
chmod +x uninstall_mac.sh
./uninstall_mac.sh

스크립트가 서버를 중지하고, 자동 시작을 제거하고, 데이터를 유지할지 삭제할지 물어봅니다.

수동 제거 (직접 하고 싶은 경우)

터미널을 열고 다음 명령을 실행하세요:

launchctl unload ~/Library/LaunchAgents/com.dashboard.startpage.plist
rm ~/Library/LaunchAgents/com.dashboard.startpage.plist

그런 다음 프로젝트 폴더를 삭제하세요.

Linux

터미널을 열고 다음 명령을 실행하세요:

sudo systemctl stop dashboard
sudo systemctl disable dashboard
sudo rm /etc/systemd/system/dashboard.service
sudo systemctl daemon-reload

그런 다음 프로젝트 폴더를 삭제하세요.

❓ 문제 해결

페이지가 열리지 않습니다 (“이 사이트에 연결할 수 없음”)
  1. restart.bat을 더블클릭하여 서버를 재시작하세요
  2. 주소가 http://localhost:1111인지 확인하세요 – “https”가 아닌 “http” (“s” 없이)
  3. 포트를 변경했다면 올바른 번호를 사용하세요 (예: http://localhost:8080)
  4. Node.js가 작동하는지 확인하세요: 명령 프롬프트를 열고 (Windows 키를 누르고 cmd를 입력, Enter), node -v를 입력한 뒤 Enter를 누르세요. v22.19.0 같은 버전 번호가 보여야 합니다
    • 버전 번호가 보이면 Node.js는 정상입니다 – setup_windows.bat을 다시 실행해 보세요
    • “명령으로 인식되지 않습니다”라고 나오면 setup_windows.bat을 다시 실행하여 Node.js를 재다운로드하세요
“포트가 이미 사용 중입니다” 오류

컴퓨터의 다른 프로그램이 이미 해당 포트 번호(방 번호(door number))를 사용하고 있습니다.

해결 방법: 1. set-port.bat을 더블클릭하고 다른 번호를 선택하세요 (예: 2222, 8080, 또는 9999) 2. restart.bat을 더블클릭하여 서버를 재시작하세요 3. 크롬 시작 페이지 주소를 새 포트에 맞게 업데이트하세요 (예: http://localhost:8080)

북마크 아이콘이 표시되지 않습니다

아이콘은 인터넷에서 자동으로 다운로드됩니다. 누락된 경우: - 아이콘을 처음 로드하려면 인터넷 연결이 필요합니다 - 일부 웹사이트는 아이콘을 제공하지 않습니다 – 대신 사이트 이름의 첫 두 글자가 표시됩니다 - 시스템이 포기하기 전에 4가지 다른 소스를 자동으로 시도합니다 - 인터넷이 연결되어 있는데도 아이콘이 나타나지 않으면 잠시 기다리세요. 자동으로 재시도됩니다

데이터가 저장되지 않습니다 (“저장 실패” 메시지)
  1. 서버가 중지되었을 수 있습니다 – restart.bat을 더블클릭하세요
  2. 프로젝트 폴더 안에 data/ 폴더가 있는지 확인하세요
  3. 폴더가 없으면 data라는 이름의 빈 폴더를 만드세요
  4. 폴더가 “읽기 전용”으로 설정되어 있지 않은지 확인하세요 (프로젝트 폴더를 우클릭 > 속성 > “읽기 전용” 체크 해제)
업데이트 후 페이지가 깨져 보입니다

브라우저가 이전의 캐시된 파일을 사용하고 있습니다. 해결 방법: 1. 크롬에서 Ctrl+Shift+Delete를 누르세요 2. “캐시된 이미지 및 파일”을 체크하고 기간을 “지난 1시간”으로 설정하세요 3. “데이터 삭제”를 클릭하세요 4. 페이지를 새로고침하세요 (Ctrl+R 또는 F5)

재부팅 후 서버가 자동 시작되지 않습니다

v7.4부터 Windows는 자동 시작을 레지스트리 + 시작프로그램 폴더 두 곳에 동시에 등록하고, 서버가 켜질 때마다 스스로 점검·복구하므로 이 문제가 훨씬 줄었습니다. 그래도 계속 발생한다면:

  • Windows: setup_windows.bat을 다시 실행하여 자동 시작을 재등록하세요 (일부 백신 프로그램이 두 등록 방법을 모두 지우는 경우, 재실행하면 다시 복구됩니다)
  • Mac: ./setup_mac.sh를 다시 실행하세요
  • Linux: sudo systemctl enable dashboard를 실행하세요
서버를 재시작하고 싶습니다

두 가지 방법: - 대시보드에서: 설정 > 데이터 > “서버 재시작” 버튼 - 파일에서: restart.bat 더블클릭

두 방법 모두 대시보드 서버만 안전하게 중지합니다. 컴퓨터의 다른 프로그램은 절대 영향받지 않습니다.

시작할 때 검은 창이 잠깐 나타납니다

정상적으로는 서버가 백그라운드에서 보이지 않게 시작되며 창이 나타나지 않아야 합니다. 컴퓨터를 시작할 때마다 짧은 검은 창(명령 프롬프트)이 보인다면:

  1. setup_windows.bat을 다시 실행하세요
  2. 서버가 보이는 창 없이 백그라운드에서 실행되도록 자동 시작을 올바르게 재등록합니다
데이터를 다른 컴퓨터로 옮기고 싶습니다

방법 1 (권장): 1. 기존 컴퓨터에서: 설정 > 데이터 > 내보내기 – JSON 파일을 저장하세요 2. 새 컴퓨터에서: 대시보드를 설치한 뒤, 설정 > 데이터 > 가져오기 – 파일을 선택하세요

방법 2 (수동 복사): - 기존 컴퓨터의 data/ 폴더 전체를 복사하여 새 컴퓨터의 프로젝트 폴더 안 같은 위치에 붙여넣으세요

❔ 자주 묻는 질문 (FAQ)

“문제 해결”이 오류가 생겼을 때 보는 곳이라면, 여기는 오류는 없지만 궁금한 점을 위한 곳입니다.

이거 정말 안전한가요? 제 정보가 어디로 새어나가지는 않나요?

네, 안전합니다. 이 대시보드는 제 컴퓨터 안에서만 동작하는 프로그램이고, 서버는 127.0.0.1(내 컴퓨터 자신을 가리키는 특수 주소)에만 응답하도록 만들어져 있어 애초에 인터넷으로 나갈 방법이 구조적으로 없습니다. 날씨 위젯 하나만 예외로, 날씨 정보를 받아오기 위해 OpenWeatherMap이라는 외부 서비스에 도시 이름만 보냅니다(이 기능을 안 쓰면 이마저도 전혀 일어나지 않습니다). 그 외 북마크·메모·할 일 같은 개인 데이터는 전부 내 컴퓨터의 data/ 폴더 안 파일로만 저장됩니다.

돈이 드나요? 나중에 유료로 전환되나요?

아니요. 이 프로젝트는 완전히 무료이고, MIT 라이선스로 배포됩니다(자세한 내용은 라이선스 & 법적 고지 참고). 나중에 유료로 바뀔 걱정 없이 그대로 계속 쓰실 수 있고, 원한다면 코드를 직접 수정해서 쓰셔도 됩니다.

인터넷이 없어도 쓸 수 있나요?

네, 날씨 위젯을 제외한 모든 기능이 인터넷 없이 작동합니다. 서버가 내 컴퓨터 안에서 자체적으로 돌아가기 때문입니다.

같은 와이파이를 쓰는 다른 사람(가족, 룸메이트 등)도 제 대시보드를 볼 수 있나요?
