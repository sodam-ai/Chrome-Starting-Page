1. 이게 뭔가요? (프로젝트 한눈에 보기)

크롬(Chrome)은 구글이 만든 인터넷 브라우저(웹사이트를 보는 프로그램)입니다. 크롬을 켜거나 새 탭(+ 버튼)을 누르면 뜨는 첫 화면을 "새 탭 페이지" 또는 "시작 페이지"라고 부릅니다.

이 프로젝트, Chrome Starting Page Dashboard는 그 첫 화면을 여러분만의 개인 비서 화면으로 바꿔주는 프로그램입니다. 이 화면 하나에서:

  • 자주 가는 웹사이트 주소(북마크)를 카테고리별로 정리해서 볼 수 있고
  • 간단한 메모를 적을 수 있고
  • 할 일 목록(오늘 할 일, 중요한 일)을 관리할 수 있고
  • 달력(캘린더)으로 일정을 볼 수 있고
  • 뽀모도로 타이머(25분 집중 + 5분 휴식을 반복하는 시간관리 방법)를 쓸 수 있고
  • 매일 하는 습관(운동, 독서 등)을 체크할 수 있습니다

꼭 알아두면 안심되는 3가지

  1. 여러분의 컴퓨터 안에서만 돌아갑니다. 이 프로그램은 인터넷 저 너머의 회사 서버가 아니라, 지금 이 컴퓨터 안에서만 실행되는 아주 작은 프로그램(서버라고 부릅니다 — "요청을 받으면 응답해주는 프로그램"이라는 뜻)입니다. 여러분이 적은 북마크나 할 일은 전부 이 컴퓨터의 폴더 안에 파일로만 저장됩니다. 회원가입도, 로그인도 없습니다.
  2. 아무것도 추가로 설치할 필요가 없습니다. 보통 프로그램들은 실행하려면 이것저것 다른 부품(라이브러리)을 추가로 받아야 하는데, 이 프로그램은 그런 게 하나도 없습니다. Node.js(3장에서 설명)만 있으면 바로 실행됩니다.
  3. 회사에서 써도, 고쳐서 팔아도 법적으로 문제없습니다. "MIT 라이선스"라는, 아주 자유로운 조건으로 배포됩니다. 자세한 건 18장에서 다룹니다.

2. 시작하기 전에 확인할 것 (사전 준비물)

아래 체크리스트를 하나씩 확인해보세요. 모르는 용어는 옆 설명을 참고하세요.

  • ☐ 운영체제(OS, 컴퓨터를 움직이는 기본 프로그램)가 Windows 10/11 또는 macOS인가요? — Windows는 시작 메뉴(왼쪽 아래 창문 모양 아이콘)가 있고, Mac은 화면 위에 애플(사과) 로고가 있습니다.
  • ☐ 컴퓨터에 여유 저장 공간이 100MB 이상 있나요? — 웬만한 컴퓨터는 이미 충분합니다.
  • ☐ 크롬(Chrome) 브라우저가 설치되어 있나요? — 없다면 https://www.google.com/chrome/에서 먼저 설치하세요.
  • ☐ 터미널(글자로 명령을 입력하는 검은 화면)을 한 번도 안 써봤나요? — 괜찮습니다. Windows는 더블클릭만으로 설치가 끝납니다. Mac만 딱 한 줄, 명령어를 입력하면 됩니다.
  • ☐ 지금 인터넷이 연결되어 있나요? — 설치할 때 1번은 필요할 수 있습니다. 설치가 끝난 뒤에는 대부분 오프라인으로도 동작합니다.
  • ☐ (선택) 날씨 위젯도 쓰고 싶은가요? — 그렇다면 무료 날씨 API 키가 필요한데, 완전히 선택사항입니다.

3. 꼭 필요한 프로그램

Node.js가 뭔가요?

Node.js는 웹사이트를 만들 때 쓰는 프로그램 실행기입니다. 이 대시보드의 "서버"를 실제로 실행시켜 주는 엔진이라고 생각하면 됩니다. Node.js 버전 18 이상이 필요합니다.

Windows 사용자는? → 그냥 넘어가세요!

[5장 설치 방법](#install)에서 실행할 setup_windows.bat 파일이, 컴퓨터에 Node.js가 없다는 걸 확인하면 자동으로 공식 사이트(nodejs.org)에서 받아서 설치해 줍니다.

Mac 사용자는? → 먼저 1번만 설치해주세요

방법 A — 공식 홈페이지 (초보자 추천)

  1. https://nodejs.org 접속
  2. "LTS" 버전 다운로드 → 설치 파일 실행

방법 B — Homebrew

brew install node

확인법: 터미널에서 node -v → v18.0.0 이상이면 성공.

5. 설치 방법 (한 걸음씩)

🪟 Windows에서 설치하기

  1. 폴더를 엽니다.
  2. setup_windows.bat을 더블클릭합니다.
  3. 검은 화면이 뜨고 자동으로: 기존 데이터 백업 → Node.js 확인/설치(필요시) → 자동 시작 등록 → 서버 시작.
  4. 완료 메시지에 http://localhost:1111 같은 주소가 나옵니다.
  5. 창은 닫아도 됩니다 — 서버는 계속 실행됩니다.

잘 안 될 때: Node.js 다운로드에서 멈추면 인터넷 확인 후 재실행하세요.

🍎 macOS에서 설치하기

  1. Node.js 설치 확인 (node -v)
  2. 터미널 열기 (Cmd+Space → terminal)
  3. cd 폴더경로로 이동
  4. bash setup_mac.sh 실행
  5. 완료 메시지에 주소가 나오면 성공
참고: 이 설치는 자동 시작 등록 외엔 어떤 시스템/Chrome 설정도 건드리지 않습니다. Chrome 새 탭 지정은 사용자가 직접 하는 별도 단계입니다(6장 4단계).

8. 사용 방법 (기능 하나하나 설명)

8.1 검색 & 통합 검색

  • 검색창 입력 후 Enter → 기본 검색엔진으로 이동
  • yt 고양이 → YouTube, nv 날씨 → 네이버, gh react → GitHub
  • F 키 → Spotlight 통합 검색(북마크·할 일·메모), 한글 초성 검색 지원
  • Spotlight에서 >todo, >timer 15, >settings 등 명령어 사용 가능

8.2 북마크(즐겨찾기) 카드

  • "+" 또는 편집 모드(E)로 추가/수정/삭제
  • 드래그로 순서 변경/카테고리 이동, 우클릭 메뉴(고정/수정/삭제 등)
  • 주소창 URL 드래그로 즉시 추가, Ctrl+V 붙여넣기로 빠른 추가
  • 7일 이내 "NEW" 표시, 끊긴 링크 자동 감지(3회 실패), 휴지통 30일 보관

8.3 메모(노트) 카드

  • 여러 개 생성, 더블클릭 이름변경, 자동 링크, 간단 마크다운(**굵게**, `코드`, [글자](주소))

8.4 할 일(To-do) 카드

  • 중요도 4단계, 마감일, 태그, 하위 작업, 반복(매일/평일/매주/매달), 칸반/전체보기, 100% 완료 시 컨페티

8.5 캘린더(달력)

  • 월/주 보기, 날짜 클릭 추가(!로 할 일 등록), 반복 일정, 10분 전 알림

8.6 뽀모도로 타이머 & 습관 트래커

  • 25분 집중/5분 휴식 자동 반복, 습관 목록 매일 체크·연속기록

8.7 화면 꾸미기 (⚙ 설정 → 외관)

  • 다크/라이트/시스템 따라가기, 강조 색상 6종, 배경 슬라이드쇼, 블러/투명도, 레이아웃 4종

9. 작동 방법 (왜 이렇게 되는지 원리)

여러분이 보는 화면(브라우저)이 "저장해줘"라고 말을 걸면, 컴퓨터 안에서 조용히 돌아가는 작은 서버가 그 내용을 파일로 저장해줍니다.

  1. http://localhost:1111을 열면 서버가 화면을 보내주고, 화면은 곧바로 자기 데이터를 서버에 요청해서 채웁니다.
  2. 뭔가 바꾸면 잠깐(1초 이내) 기다렸다가 서버에 저장 요청 → 임시 파일에 먼저 쓰고 이름을 바꾸는 방식으로 안전하게 저장
  3. 연결이 끊기면 "오프라인 모드" 배너가 뜨고, 변경 내용은 브라우저 임시 보관함에 저장되었다가 연결 복구 시 자동 저장 — 데이터는 사라지지 않습니다
  4. 여러 탭을 열면 한 탭의 저장이 다른 탭에도 새로고침 신호를 보내 서로 맞춰줍니다
  5. 인터넷 없어도 화면이 뜨는 건 서비스워커가 화면 파일을 미리 저장해두기 때문(단, 데이터 통신은 서버 연결 필요)
  6. 서버는 부팅 시 데이터 무결성 검사·자동 복구, 하루 1회 자동 백업을 스스로 합니다

14. 아키텍처 (구조 이해하기)

① 브라우저 화면(index.html, script.js, style.css)
        ↕  (내 컴퓨터 안에서만 오가는 신호, 포트 1111)
② 작은 서버 프로그램(server.js) — 이 컴퓨터에서만 실행됨
        ↕
③ data 폴더 안의 파일들(JSON) — 진짜 데이터가 저장되는 곳
  • ①(화면): 순수 HTML/CSS/JS, 특별한 프레임워크 없음
  • ②(서버): 화면의 요청을 처리해 ③에 반영하는 다리 역할, 이 컴퓨터에서만 실행
  • ③(데이터 파일): 폴더째 복사하면 다른 컴퓨터로도 이동 가능

15. 보안 / 데이터 흐름 (내 정보는 안전한가?)

결론부터: 안전합니다.

  • 서버는 이 컴퓨터 자기 자신하고만 대화합니다(127.0.0.1, "localhost"). 다른 컴퓨터/휴대폰은 절대 접속 불가.
  • 여러분이 입력한 정보는 어디에도 전송되지 않고 data 폴더에만 저장됩니다.
무엇을 위해 인터넷에 연결되나요언제내 정보가 전송되나요?
글꼴 불러오기화면을 열 때마다아니요, 디자인용 글씨체만
북마크 아이콘 불러오기북마크가 보일 때아니요, 아이콘 이미지만
날씨 정보API 키를 직접 넣었을 때만넣지 않으면 통신 자체가 없음
북마크 생존 확인가끔 자동으로저장된 주소로만 확인, 개인정보 없음

코드 전체 확인 결과 광고, 추적, 몰래 전송 기능은 전혀 없습니다. 유일한 예외는 Windows 설치 시 Node.js가 없을 때 딱 1번 nodejs.org에서 받는 것뿐입니다.

16. 문제/오류 대처 방법 (그림처럼 따라하기)

증상: "서버 연결 끊김"이 나와요.
→ 몇 초 기다려보기 → Windows는 restart.bat, Mac은 launchctl load ~/Library/LaunchAgents/com.dashboard.startpage.plist

증상: "이 사이트에 연결할 수 없음"이라고 떠요.
→ port.conf 파일에서 실제 포트 확인 후 재접속

증상: 새 버전인데 화면이 예전 그대로예요.
→ Ctrl+Shift+R(Mac: Cmd+Shift+R) 강력 새로고침

증상: 포트를 바꿨는데 그대로예요.
→ restart.bat 실행 또는 설정의 "서버 재시작" 버튼

증상: 데이터가 이상해졌거나 사라진 것 같아요.
→ 설정 → 데이터 탭 → 백업 목록에서 복원, 또는 휴지통(30일)

증상: 완전히 지우고 싶어요.
→ Windows: uninstall.bat / Mac: bash uninstall_mac.sh (데이터 삭제 여부 직접 확인)
